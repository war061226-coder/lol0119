Windows에서 실행하는 방법
========================

[Node.js가 필요 없는 버전]

1. "windows-release" 폴더 전체를 Windows 컴퓨터에 복사합니다.
2. 폴더 안의 "LoL-커스텀-밸런서.exe"를 더블클릭합니다.
3. 잠시 기다리면 전용 프로그램 창이 열립니다.

이 버전은 Node.js를 별도로 설치할 필요가 없습니다.
브라우저가 아니라 전용 프로그램 창으로 열립니다.
플레이어·밸런싱·내전 기록은 Windows 사용자 데이터 폴더에 안전하게 저장됩니다.
기존 프로젝트의 data 폴더 기록은 첫 실행 때 자동으로 가져옵니다.
이전 버전의 EXE가 있다면 반드시 새 EXE로 교체해서 사용하세요.

[개발용 프로젝트 폴더에서 실행하는 방법]

1. 이 프로젝트 폴더 전체를 컴퓨터에 복사합니다.
2. Node.js LTS가 설치되어 있는지 확인합니다.
   - https://nodejs.org/ 에서 LTS 버전을 설치하면 됩니다.
3. 프로젝트 폴더 안의 "실행.bat"을 더블클릭합니다.
4. 잠시 기다리면 브라우저에서 프로그램이 자동으로 열립니다.

처음 실행할 때는 필요한 패키지를 자동으로 설치하므로 조금 더 오래 걸릴 수 있습니다.

중요
----
- "실행.bat" 창을 닫으면 프로그램도 종료됩니다.
- Node.js가 필요 없는 배포 버전에서는 EXE 창을 닫으면 프로그램이 종료됩니다.
- 프로그램 기록은 data 폴더에 저장됩니다.
- data/manual-players.json: 수동 플레이어 데이터
- data/balance-history.json: 밸런싱 및 내전 기록
- 기록을 유지하려면 data 폴더를 삭제하지 마세요.

문제 해결
----------
- Node.js 오류가 나오면 Node.js LTS를 설치한 뒤 다시 실행합니다.
- 이미 5000번 포트를 사용 중이면 기존 프로그램을 종료한 후 다시 실행합니다.
- 시작에 실패하면 프로그램 창에 오류 내용이 표시됩니다.
- 상세 오류는 `%APPDATA%\loL-custom-balancer\startup.log`에서 확인할 수 있습니다.
